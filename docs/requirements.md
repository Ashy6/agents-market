# Agents Market 产品需求文档

## 1. 产品概述

**产品名称：** Agents Market
**版本：** 0.1.0
**定位：** 一个支持多 AI 模型、多 Agent 配置的流式对话 Web 应用

用户可在同一界面下管理多个具有不同系统提示词和模型参数的 Agent，通过切换 Agent 即可切换对话角色和模型能力，对话历史自动持久化到本地。

---

## 2. 目标用户

- 需要频繁切换 AI 角色/能力场景的用户（开发者、内容创作者、研究者）
- 希望比较不同大模型效果的用户
- 有私有化部署或自定义系统提示词需求的用户

---

## 3. 核心功能需求

### 3.1 Agent 管理

| 功能            | 描述                                           | 优先级 |
| --------------- | ---------------------------------------------- | ------ |
| 查看 Agent 列表 | 左侧侧边栏展示所有可用 Agent，按模型提供商分组 | P0     |
| 选择 Agent      | 点击 Agent 切换当前对话上下文                  | P0     |
| 新建 Agent      | 通过弹窗配置名称、模型、系统提示词、温度参数   | P0     |
| 编辑 Agent      | 修改已有 Agent 的配置参数                      | P1     |
| 克隆 Agent      | 以现有 Agent 为模板快速创建新 Agent            | P1     |
| 搜索 Agent      | 按名称/模型/提示词关键词过滤列表               | P1     |
| 删除 Agent      | 删除自定义 Agent（内置 Agent 不可删除）        | P2     |

**Agent 属性字段：**

- `name`：Agent 名称（必填，唯一标识符）
- `modelId`：使用的模型 ID（必填，来自模型目录）
- `systemPrompt`：系统提示词（必填，定义 AI 角色和行为）
- `temperature`：温度参数 0~2（可选，默认 0.7，控制回答随机性）

### 3.2 对话功能

| 功能       | 描述                                     | 优先级 |
| ---------- | ---------------------------------------- | ------ |
| 发送消息   | 文本框输入后发送，支持 Markdown 渲染     | P0     |
| 流式输出   | AI 回答以 SSE 流逐字显示，实时反馈       | P0     |
| 新建对话   | 清空当前会话历史，开始新对话             | P0     |
| 加载历史   | 切换 Agent 时自动恢复该 Agent 的对话历史 | P0     |
| 复制消息   | 鼠标悬停显示操作按钮，一键复制消息内容   | P1     |
| 重新生成   | 对 AI 回复重新请求生成                   | P1     |
| 删除消息   | 删除单条消息记录                         | P1     |
| 键盘快捷键 | Cmd/Ctrl+Enter 发送，Cmd/Ctrl+N 新对话   | P1     |

### 3.3 模型支持

| 模型类别      | 支持模型            | 能力                         |
| ------------- | ------------------- | ---------------------------- |
| 豆包 Pro 32k  | `doubao-pro-32k`    | 长文本、流式、工具调用、JSON |
| DeepSeek R1   | `deepseek-r1-*`     | 数学、代码、逻辑推理         |
| DeepSeek V3   | `deepseek-v3-*`     | 通用、写作、Agent 任务       |
| 豆包 Seedream | `doubao-seedream-*` | 图片生成（不支持聊天对话）   |
| GPT-4o        | `gpt-4o`            | 高质量多模态                 |
| GPT-4o mini   | `gpt-4o-mini`       | 快速、经济                   |

> 注：Seedream 系列为图像生成模型，不支持对话，发送消息时会收到提示说明。

### 3.4 对话历史持久化

- 对话记录保存在浏览器 `localStorage`，按 `agentId` 隔离
- 自动清理 30 天以前的历史记录
- 存储上限约 5MB，接近上限时提示用户
- 切换 Agent 时自动加载/保存对应历史

### 3.5 健康检查 & 配置检测

- 访问 `/api/healthcheck` 可查看各 Provider 配置状态及可用模型列表
- 未配置 API Key 时，对应 Provider 的模型无法使用

## 4. 界面布局需求

### 4.1 桌面端布局（≥768px）

```
┌──────────────────────────────────────────┐
│  Header: "AI Chat"                        │
├────────────┬─────────────────────────────┤
│            │                             │
│  Agent     │    Chat Messages Area       │
│  Sidebar   │    (消息列表 + 滚动)          │
│  (w=320px) │                             │
│            ├─────────────────────────────┤
│  - 搜索框  │  Footer:                    │
│  - 豆包组  │  当前 Agent + 新对话按钮     │
│  - OpenAI组│  输入框 + 发送按钮           │
└────────────┴─────────────────────────────┘
```

```
┌────────────────────────┐
│ ☰  AI Chat    Agent名  │   ← Header（含汉堡菜单）
├────────────────────────┤
│                        │
│   Chat Messages Area   │   ← 全屏消息区
│                        │
├────────────────────────┤
│ 当前Agent | 新对话      │
│ ┌──────────────┐ [发送] │   ← 输入区
│ │              │       │
└────────────────────────┘
     ↓ 点击汉堡菜单
┌────────────────────────┐
│ × 可用 Agents          │   ← 滑入侧边栏（overlay）
│ ┌──────────────────┐   │

│   · Agent 2           │

└────────────────────────┘
```

## 5. 非功能需求

| 类别     | 要求                                                                         |
| -------- | ---------------------------------------------------------------------------- |
| 响应速度 | 流式输出延迟 < 500ms 首字节                                                  |
| 兼容性   | 支持 Chrome、Firefox、Safari、Edge 最新版；移动端 iOS Safari、Android Chrome |
| 可用性   | 无后端时前端可展示空状态，不崩溃                                             |
| 安全性   | API Key 不暴露于前端，由后端持有；CORS 白名单控制                            |
| 可扩展性 | 后端模型列表集中管理，新增模型只需在 `list.ts` 中追加                        |
| 部署     | 前端静态托管；后端 Cloudflare Workers 无服务器部署                           |

---

## 6. 错误处理需求

| 场景                | 处理方式                                       |
| ------------------- | ---------------------------------------------- |
| 网络请求失败        | 输入区显示错误提示，不崩溃                     |
| 模型 ID 不存在      | 后端返回 404，前端显示错误消息                 |
| 未选择 Agent 就发送 | 发送按钮不可点击                               |
| 创建 Agent 字段为空 | 表单内联错误提示，阻止提交                     |
| localStorage 存储满 | 提示清理历史，不影响当前对话                   |
| Provider 未配置     | Healthcheck 接口返回状态，前端可展示不可用标记 |
